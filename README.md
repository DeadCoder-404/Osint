## Run Locally (Install)
1. Clone the Project:
   `git clone https://github.com/DeadCoder-404/Osint.git`
**Prerequisites:**  Node.js

2. Install dependencies:
   `npm install`
3. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
4. Run the app:
   `npm run dev`
